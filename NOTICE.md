# Attribution and distribution status

Original mod: **Not Enough Revives**, by **Sir Terminator**. Original metadata declares **All rights reserved**. This repository contains a selective reconstruction with changes branded **Not Enough Revives Reforged** and retains the original mod ID/package for compatibility.

No open-source license or original-author redistribution permission is asserted. The original base JAR and generated combined JARs are excluded from Git. Obtain the original dependency separately. Public distribution of reconstructed source or combined binaries requires appropriate permission; the existing README records that permission has not been established.

The Gradle wrapper is build tooling and remains checked in so the pinned build can be launched. Dependencies retrieved by Gradle retain their respective licenses.
